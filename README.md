# Indian Heritage

Interactive Indian Heritage & Cultural Discovery Platform

## Stack

- Vite + React
- Tailwind CSS
- React Router
- React Simple Maps

## Features

- Interactive India → State → District → Tradition cultural atlas
- Heritage at Risk discovery
- Traditional crafts exploration
- Heritage trails
- Multilingual support
- AI-assisted heritage discovery
- Culture quiz
- State-wise heritage information

## Run locally

```bash
npm install
npm run dev
